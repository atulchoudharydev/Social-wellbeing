# Week 3: Prototype (Version 1) and Peer Feedback

## What I did
- Built the first working prototype of Option C in HTML, CSS and JavaScript
- Created all six required pages: Home, Services, Events, Book a place, Contact, News and stories
- Added the main components: accordion directory, calendar, 4-step booking form and mobile menu
- Asked for feedback on the look and feel

## Version 1 at a glance
- Teal and orange colour scheme
- Emoji used as icons
- Gradient background on the homepage banner

## Feedback notes

| Feedback | My response |
|---|---|
| The site feels cluttered and "tacky" | Simplify the layout and reduce decoration |
| Emoji icons look different on each device | Replace with one consistent set of line icons |
| The gradient and colours feel dated | Choose a calmer colour palette and better fonts |

## Reflection
The feedback was about the visual style, not the structure, so I kept the Option C layout and components and focused on how the site looks. I learned that a site can work and still give the wrong first impression, which matters for a service people need to trust.

**Next:** redesign the visual style (Version 2).
