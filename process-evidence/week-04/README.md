# Week 4: Redesign (Version 2) and Design Critique


## What I did
- Redesigned the visual style based on the Week 3 feedback
- Reviewed the interface against a list of common generic design patterns (design critique)
- Reviewed how the site behaves if JavaScript fails (robustness review)
- Showed Version 2 to a friend on 15 November 2026 and asked for feedback

## Changes in Version 2

| Problem (and where it came from) | Change made |
|---|---|
| Emoji icons looked different on each device (classmate, 12 Nov) | One consistent set of line icons, hidden from screen readers |
| Colours and gradient felt dated (classmate, 12 Nov) | Calmer, editorial style with new fonts (Source Serif 4 and Public Sans) |
| Navigation was added by JavaScript, so it would disappear if a script failed | Header and footer rewritten as plain HTML |
| Generic patterns: labels above headings, cream background, vanity statistics, frosted header | Removed; statistics replaced with practical facts (cost, referral, opening times) |

Also new in Version 2: a **"Display" menu** for larger text and high contrast (for personas like Margaret).

## Feedback on Version 2

**Given by:** a friend · **Date:** 15 November 2026 · **On:** Version 2

| Feedback | My response |
|---|---|
| Cleaner, but now "boring and plain" | Add real photography and more colour |
| Needs to feel more welcoming and engaging | Add an image slider and success stories |

## Reflection
Version 2 fixed the cluttered look, but I went too far the other way and it lost its warmth. For a service that wants to reach people with low mood or low confidence, looking friendly matters as much as looking clean.

**Next:** add photography and colour (Version 3), then test accessibility.
