# Week 1: Empathise and Define

*Compiled 10 November 2026 from Week 1 design work.*

## What I did
- Read the brief and listed the required pages
- Looked at similar sites (council wellbeing pages, NHS, GOV.UK) for ideas and problems
- Created personas for the Hub's main user groups
- Wrote a problem statement

## Personas

![Persona cards]

| Persona | Needs | Design idea |
|---|---|---|
| **Margaret, 72**: older adult, uses a tablet | Large text, simple booking | Text size / contrast menu, big buttons |
| **Priya, 34**: busy parent, mobile only | Find family events fast | Mobile-first, calendar with filters |
| **Daniel, 23**: anxious, new to the area | Feel welcome, know what to expect | Warm photos, plain English, success stories |
| **Samuel, 48**: screen-reader user | Keyboard access, clear errors | Skip link, ARIA patterns, error summary |

## Problem statement
Riverside residents need a simple, welcoming way to find wellbeing support and book activities on any device, because cluttered, inaccessible council websites put off the people who need help most.

**How might we** help people find the right service quickly, without jargon, whatever their device or ability?

## Reflection
The users are very mixed, but all of them need a site that is simple and not overwhelming. The personas come from research, not interviews, so they would need checking with real users.

**Next:** sketch three design options as wireframes.
